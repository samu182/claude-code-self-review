# 視点5 — 消えたガード（差分の「消えた側」だけを読む）

AI はリトライや防御コードを「不要」と判断して消す。**足した側ではなく、消した側だけを見る視点を1本立てる。**

- `git diff` で **削除された** 条件分岐・try-catch・retry・検証を1つずつ拾い、**なぜ消えたか**を `git log` / blame で遡る
- **テストを緩めていないか。** assert が消えていないか、`toHaveLength` が弱い形に置き換わっていないか
- **テストが実装をなぞっていないか。** 実装が間違っていれば、テストも同じ間違いを正解として固定する
- 異常系・境界値・空・null のテストが、正常系に比べて薄くなっていないか
